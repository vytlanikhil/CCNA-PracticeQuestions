## How to Practice

1. Navigate to the quiz you want to practice in [`Quizes/`](./Quizes/).
2. Read each scenario and test yourself by picking an answer.
3. Expand the **View Answer & Explanation** dropdown to check your answer and review the step-by-step solution.
