# CCNA Quizzes Directory

This directory contains focused practice quizzes designed to prepare candidates for the **Cisco Certified Network Associate (CCNA 200-301)** examination.

## Available Quizzes

| Quiz Name | Topic | Questions | Difficulty Range | File Link |
|---|---|---|---|---|
| **Subnetting & VLSM Quiz** | IPv4 Subnetting, VLSM, Route Summarization, Wildcard Masks | 30 | Basic to Advanced CCNA Level | [Subnetting_and_VLSM_Quiz.md](./Subnetting_and_VLSM_Quiz.md) |

## Structure & Learning Methodology

All quizzes in this directory feature:
- Progressive difficulty from basic foundational knowledge to real-world exam and design scenarios.
- Self-testing support using collapsible GitHub `<details>` blocks to keep answers hidden until you are ready.
- Step-by-step mathematical calculations, binary representations, and Cisco IOS behavior explanations for every question.
